# The Language Lab

English language teaching and assessment materials.

## A1–A2 English Level Placement Test

Official placement test PDF for CEFR **A1** and **A2**:

- **File:** [`exams/A1-A2_English_Level_Placement_Test.pdf`](exams/A1-A2_English_Level_Placement_Test.pdf)
- **Skills:** Reading (40 marks), Writing (20 marks), Speaking (20 marks)
- **Includes:** Candidate paper, answer key, writing/speaking mark schemes, score sheet, and level decision guide

### Regenerate the PDF

```bash
pip install reportlab
python3 scripts/generate_a1_a2_placement_test.py
```
