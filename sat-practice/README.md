# SAT Reading & Writing Practice Test (30 Questions)

Unofficial Digital SAT–style **Reading and Writing** practice set covering foundational topics.

## Files

| File | Description |
|------|-------------|
| `SAT_Reading_Writing_Practice_Test_30.pdf` | Ready-to-print test + answer key |
| `generate_sat_rw_test.py` | Script that builds the PDF |

## Topic breakdown

| Questions | Skill |
|-----------|--------|
| 1–5 | Words in Context |
| 6–9 | Central Ideas & Details |
| 10–12 | Inferences |
| 13–15 | Command of Evidence |
| 16–17 | Text Structure & Purpose |
| 18–20 | Transitions |
| 21 | Rhetorical Synthesis |
| 22–25 | Boundaries (punctuation) |
| 26–30 | Form, Structure & Sense (grammar) |

Suggested time: about **32 minutes**.

## Regenerate the PDF

```bash
pip install reportlab
python3 generate_sat_rw_test.py
```

Requires DejaVu fonts at `/usr/share/fonts/truetype/dejavu/` (for Turkish characters on the cover).
